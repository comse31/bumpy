# Уровни Bumpy, отсортированные по сложности

Сложность = взвешенная сумма критериев:

1. **ловушки** — шипы, горящие, сжимающиеся, липкие, наклонные платформы;
2. **обязательные одновременные действия** — высокие прыжки с перестроением
   в полёте, вынужденные отскоки с наклонных, скатывания с липких, ресурсные «замки»;
3. **невозможность задержаться на месте** — ячейки плана, где шар не может
   спокойно стоять (наклонные/липкие/сжимающиеся/горящие).

Решено уровней: **0** из 1. Не решены: 1.
