# План прохождения уровней (режим classic)

Документ генерируется [`tools/gen_walkthrough.py`](gen_walkthrough.py:1):
каждый план найден решателем [`tools/solve_level.py`](solve_level.py:1) по
метаданным [`main/levels.json`](../main/levels.json:1) и проверен его моделью
правил (платформы, перегородки, кладка, огонь, шипы, липкие, наклоны,
сжимающиеся платформы, открытие выхода).

Координаты: `(row, col)`, где **row 0 — нижний ряд**, `col 0` — левая
колонка. Перегородки нумеруются по границам: `b1` — между колонками 0 и 1,
`b5` — между 4 и 5.

«Снаряжение на старте» — минимум, который должен быть в кармане перед
началом уровня (остальное можно подобрать по пути). Если этого нет, игра
сразу завершается плашкой NOT ENOUGH THINGS (см.
[`main/ball/ball_progress.lua`](../main/ball/ball_progress.lua:1)).

## Как играть по плану

| Шаг плана | Что делать в игре |
|---|---|
| хоп (r,c) → (r2,c2) | короткое нажатие прыжка в сторону нужной колонки |
| высокий прыжок с отводом в (r2,c2) | удержать прыжок, в полёте нажать ячейку нужной колонки |
| высокий прыжок на месте (r,c) | удержать прыжок, никуда не отводя |
| пробить перегородку bN | прыгнуть в сторону перегородки (ключ тратится ударом) |
| разбить кладку снизу | стоять под кладкой и жать прыжок (тратится молоток) |
| отскок от перегородки/кладки | действие с сжимающейся платформы, шар остаётся на ней |

Ключи и молотки тратятся автоматически при ударе; капля гасит горящую
платформу при приземлении на неё. Фрукты собираются пролётом — отдельного
действия не требуют.

## Легенда карты

Каждая ячейка карты — два символа: платформа и предмет в ней.

| Символ | Платформа |
|---|---|
| `=` | обычная платформа |
| `3/2/1` | сжимающаяся: остаток использований |
| `~` | липкая |
| `</>` | наклонная (влево/вправо) |
| `*` | горящая (нужна капля или смерть) |
| `%` | горящая и липкая |
| `#` | кирпичная кладка (молоток) |
| `^` | шипы (смерть) |
| `.` | пусто |

| Символ | Предмет |
|---|---|
| `H` | молоток |
| `K` | ключ |
| `d` | капля (гасит огонь) |
| `L` | жизнь |
| `o` | фрукт: открывает выход, когда собрано нужное число |
| `.` | нет предмета |

| Код перегородки | Прочность |
|---|---|
| `3` | разрушаемая, 3 удара = 3 ключа |
| `2` | разрушаемая, 2 удара = 2 ключа |
| `1` | разрушаемая, 1 удар = 1 ключ |
| `4` | неразрушаемая (только обойти) |
