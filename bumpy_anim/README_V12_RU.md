## Удары о стену: ЧЕМ ударился, определяется по кадру, который играется в момент удара
1. clip = текущий клип, i = индекс его текущего кадра (по курсору).
2. В bumpy_v12_phi.lua: T = PHI[clip], sinv = T.sin[i], cosv = T.cos[i]. Значения даны для незеркального клипа.
3. s = scale.x героя (+1 или -1). Волосы на экране смотрят по x: hx = s * sinv.
4. Правая стена: hx > 0.15 -> голова; hx < -0.15 -> ноги. Левая стена: hx < -0.15 -> голова; hx > 0.15 -> ноги.
5. Если |hx| <= 0.15 (волосы строго вверх или вниз): cosv > 0 (стоит на ногах) -> ноги ведут (шар упёрся в стену нижней частью), иначе голова.
6. Клип: head_hit_side_up/feet_hit_side_up, если до удара cosv > 0 (был на ногах), иначе head_hit_side_inv/feet_hit_side_inv. Клипы нарисованы для ПРАВОЙ стены: для левой ставь scale.x = -1.
7. Для клипов без записи в таблице (contact_*) sin = 0: пункт 5.
Лог: WALLHIT clip=... frame=... s=... hx=... leading=head|feet.

## Лицо
Спокойное (calm) в движении. Моргание 0.16 с. Зажмурено: удары о потолок и стены. Удивлённое: fall_surprised. hurt: worried/dizzy. death: dead. Большая улыбка только win и collect. Поворот в сторону: только глаза, 2D.

## Наклонные платформы
Отдельных кадров нет: поворачивай спрайт на угол наклона вокруг точки касания, клип тот же. Только если механика подтверждена.
